## 📦 Продукты в составе LazySuite
### 1. ⚡ LazyTray — Системная телеметрия и Game Mode (CS2)
* **Живой мониторинг:** нагрузка и температуры CPU / GPU / RAM, дисковая активность и заряд беспроводной периферии.
* **Game Mode (CS2):** очистка Standby RAM, схема электропитания, контроль задержек DPC и Smart Anti-Cheat Guard (FACEIT AC / Riot Vanguard).
* **Game Advisor:** встроенный движок рекомендаций по устранению фризов и просадок FPS.
### 2. 🩺 LazyPChealth — Диагностика SSD, BSOD и спасение данных
* **Здоровье дисков и MFT:** SMART-анализ SSD/NVMe, быстрый аудит занятого места по таблице MFT, перенос файла подкачки.
* **Разбор сбоев:** инспектор дампов синих экранов (BSOD) и аппаратных ошибок WHEA.
* **Работа с секторами (Pro / B2B):** LBA-сканер поверхности диска, сопоставление сбойных секторов NTFS с файлами и безопасное спасение данных.
